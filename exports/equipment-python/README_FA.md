# سورس فعلی اتصال، بررسی و رفع FAM

فقط بخش درخواستی، نه برنامهٔ کامل یا نصاب:

- `server/equipment_probe.py`: اتصال مستقیم Windows OpenSSH، فرمان‌های ثابت، اعتبارسنجی جدول، بررسی/توضیحات، pre-check / shutdown / no shutdown / post-check؛ ASKPASS موقت بدون رمز.
- `server/equipment_ops.py`: API احرازهویت‌شده، کنترل عملیات و مقصد، بررسی ورودی و ticket تأیید پورت.
- `src/equipment-live-server.js`: فرم اتصال، انتخاب سوئیچ/IP دستی، نتیجه و پورت، تأیید/انصراف رفع و نمایش پالایش‌شدهٔ توضیحات؛ credential فقط RAM.

این‌ها سورس اصلی بدون تغییر از پروژه هستند؛ استخراج‌شان برنامهٔ مستقل ایجاد نمی‌کند. API به Flask، نشست/CSRF/Origin و callback دسترسی از app.py وابسته است. رابط به Access، FamShared، FamEquipmentServer و FamEquipmentInventory پروژه وابسته است. helper فقط ورودی JSON از stdin می‌گیرد؛ رمز را در argv، فایل یا chat ننویسید. نیاز اجرایی همان Windows OpenSSH و .NET Framework 4.x پروژه است.

رنج‌های RFC1918 و 100.64.0.0/10 پشتیبانی می‌شوند. رفع فقط پورت تأییدشده و با بررسی قبل/بعد است؛ Enable، فرمان آزاد و ذخیرهٔ کانفیگ ندارد. سورس به‌تنهایی جایگزین مجوز و حفاظت سرور نیست. هیچ تجهیز واقعی برای این خروجی تماس گرفته نشده و نسخهٔ فعال برنامه تغییر نکرده است.
