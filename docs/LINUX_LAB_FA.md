# راهنمای نصب آزمایشگاه FAM روی Ubuntu — نسخه آفلاین

این بسته، همان برنامه FAM را به‌صورت آفلاین روی ماشین Ubuntu آزمایشگاه اجرا
می‌کند: برنامهٔ اصلی + وب‌سرور nginx با HTTPS. همهٔ کتابخانه‌های موردنیاز داخل
بسته است و برای نصب **هیچ اتصال اینترنتی لازم نیست**.

---

## ۱. چه چیزی لازم دارید

1. ماشین Ubuntu آزمایشگاه (FAM-Ubuntu) با Docker و این Imageهای ذخیره‌شده:
   `python:3.12-slim` و `nginx:alpine`
2. اتصال SSH از ویندوز به ماشین (مثل کارهای قبلی)
3. فایل `FAM-Linux-Lab.zip` که از صفحهٔ GitHub پروژه دانلود کرده‌اید

> یادآوری: این ماشین **نباید اینترنت داشته باشد**. همهٔ فایل‌ها را از ویندوز
> منتقل می‌کنیم.

---

## ۲. دانلود و انتقال بسته

### در ویندوز

1. فایل `FAM-Linux-Lab.zip` را از GitHub دانلود کنید.
2. روی فایل راست‌کلیک کنید و **Extract All** را بزنید؛ پوشه‌ای به نام
   `FAM-Linux-Lab` ساخته می‌شود.
3. پوشه را با scp به ماشین بفرستید (در PowerShell ویندوز):

```powershell
scp -r "$env:USERPROFILE\Downloads\FAM-Linux-Lab" mohsen@192.168.97.128:~/
```

اگر فایل را جای دیگری ذخیره کرده‌اید، مسیر همان را بنویسید.

---

## ۳. اجرا

در اتصال SSH به ماشین (خط فرمان `mohsen@fam-lab:~$`):

```bash
cd ~/FAM-Linux-Lab
sudo bash setup.sh 192.168.97.128
```

به‌جای `192.168.97.128` همان آدرسی را بنویسید که می‌خواهید در مرورگر باز کنید
(همان IP که با `ip -br addr` دیدید).

اسکریپت چند مرحله را خودش انجام می‌دهد:

- بررسی وجود Docker و Imageها
- آماده‌کردن برنامهٔ `ssh` داخل بسته (برای مدیریت تجهیزات)
- ساخت Image برنامه به‌صورت **آفلاین**
- ساخت گواهی HTTPS مخصوص آزمایشگاه
- **ساخت کاربر اول:** از شما یک رمز قوی (۱۲ کاراکتر یا بیشتر) می‌پرسد.
  رمز را جایی یادداشت نکنید و در هیچ فایلی ننویسید؛ فقط خودتان نگه دارید.
- راه‌اندازی سرویس‌ها

---

## ۴. ورود

1. در مرورگر ویندوز باز کنید:

```text
https://192.168.97.128
```

2. چون گواهی مخصوص آزمایشگاه است، مرورگر هشدار می‌دهد. این هشدار **عادی** است:
   روی **Advanced** و سپس **Proceed** کلیک کنید.
3. با نام کاربری و رمزی که ساختید وارد شوید.

> امنیت: در نسخهٔ واقعی شرکت باید از گواهی معتبر استفاده شود؛ این گواهی فقط
> برای آزمایشگاه داخلی است.

---

## ۵. داده‌ها کجا هستند؟

| مورد | مسیر |
|---|---|
| پایگاه داده | `~/FAM-Linux-Lab/data/fam.sqlite3` |
| نسخهٔ پشتیبان | `~/FAM-Linux-Lab/data/backups` (با `manage.py`) |
| کلیدهای شناسایی تجهیزات | `~/FAM-Linux-Lab/data/equipment_known_hosts` |

برای پشتیبان‌گیری امن (نه کپی ساده با Explorer):

```bash
cd ~/FAM-Linux-Lab
docker compose exec app python /app/server/manage.py backup
```

پایگاه داده **هرگز بازنشانی نمی‌شود**؛ نسخه‌های بعدی برنامه داده‌های موجود را
حفظ می‌کنند.

---

## ۶. نکته‌ها

- **آفلاین:** این نصب هیچ فایلی از اینترنت نمی‌گیرد؛ اگر جایی خطای شبکه دیدید،
  یعنی اشتباهی رخ داده است.
- **IP عوض شد؟** اگر آدرس ماشین تغییر کرد، فایل `.env` داخل پوشهٔ بسته را
  ویرایش کنید (`FAM_PUBLIC_ORIGIN=https://IP-جدید`) و بعد:

```bash
sudo docker compose up -d
```

- **نگاه به وضعیت سرویس‌ها:**

```bash
cd ~/FAM-Linux-Lab
docker compose ps
docker compose logs --tail 20
```

- **توقف:**

```bash
sudo docker compose down
```

---

## ۷. چه چیزی در این بسته نیست؟

- **PostgreSQL:** نسخهٔ فعلی با همان پایگاه دادهٔ SQLite کار می‌کند. افزودن
  PostgreSQL بعداً و همراه با مهاجرت کامل داده‌ها و آزمون بازیابی انجام
  می‌شود؛ داده‌های شما دست‌نخورده می‌مانند.
- **اتصال به تجهیزات شبکه:** ساختار اتصال مستقیم SSH آماده است، اما تعریف
  تجهیزات و کلیدهای شناسایی آن‌ها مراحل بعدی است.
- **نصب روی سرور واقعی شرکت:** این بسته فقط برای آزمایشگاه است.

---

## ۸. عیب‌یابی سریع

| مشکل | کار |
|---|---|
| `image is not loaded` | Imageها هنوز بارگذاری نشده‌اند؛ فایل‌های `fam-images.tar.gz` را با `docker load` بارگذاری کنید |
| مرورگر صفحه را باز نمی‌کند | از `docker compose ps` مطمئن شوید هر دو سرویس `Up` هستند؛ بعد `docker compose logs` را ببینید |
| پیام خطای پورت 443 | برنامهٔ دیگری پورت را گرفته؛ خروجی `sudo ss -tlnp | grep 443` را بررسی کنید |
| رمز را فراموش کرده‌ام | راه‌حل بازیابی با حفظ داده‌ها در نسخه‌های بعدی مستند می‌شود؛ داده‌ها را پاک نکنید |
