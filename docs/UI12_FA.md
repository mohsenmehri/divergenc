# UI-12 — لوگوی جدید شیشه‌ای و فارسی‌سازی عملیات

## لوگو و عنوان

- تصویر اصلی `fam-1.png` مستقیماً از شاخه `main` مخزن GitHub گرفته شد؛ شناسه blob منبع: `88d13f4776c1dc4de42b4df0fc43d18721330d6e`.
- فایل منبع بدون تغییر نگهداری می‌شود. نسخه نمایشی در `assets/fam-1-glass.png` قرار دارد و در خود `FAM.html` نیز تعبیه شده است؛ اجرای HTML به فایل تصویر بیرونی وابسته نیست.
- حاشیه تصویر با محدوده `(0, 4, 311, 320)` برش خورده و اندازه خروجی ۳۱۱×۳۱۶ است.
- سفید و خاکستری خنثیِ زمینه، از جمله خطوط مورب، شفاف شده‌اند. قاب لوگو گرادیان سفید بسیار ملایم، خط حاشیه نیمه‌شفاف و محوشدگی پشت‌زمینه دارد تا زمینه شیشه‌ای دیده شود.
- پیکسل‌های رنگیِ اشباع بدون تغییر رنگ یا کاهش شفافیت حفظ شده‌اند؛ برای لبه‌های نیمه‌رنگی، هاله سفید حذف شده است. ۳۸٬۵۵۶ پیکسل رنگیِ اشباع با منبع تطبیق بایت‌به‌بایت داده شدند. این پردازش بازطراحی یا تولید دوبارهٔ نشان نیست.
- عنوان انگلیسی مستقیماً زیر نام فارسی و در همان ستونِ کنار لوگو قرار دارد، نه زیر کل ردیف لوگو. هر دو عنوان در عرض‌های آزموده‌شده یک‌خطی می‌مانند. سربرگ همچنان ثابت است.

بازتولید فایل تصویر با Pillow:

```sh
python scripts/prepare_fam_logo.py
```

پس از تغییر تصویر خروجی باید data URI تصویر در HTML نیز به‌روزرسانی شود؛ فایل منبع اصلی را دست‌کاری نکنید.

## برچسب‌ها

- SEARCH ← جستجو
- ON / OFF ← روشن / خاموش
- ADD RECORD ← اضافه کردن داده
- REMOVE RECORD ← پاک کردن داده
- UNDO ← برگشت
- EXPORT ← خروجی (پسوند نوع فایل مثل CSV و XLSX باقی می‌ماند)
- عنوان «افزودن مورد» ← «افزودن داده»

نمایش روشن/خاموش در کنترل اصلی و نسخهٔ منوی سریع هماهنگ است. مقدار داخلی `ON`/`OFF` و شناسه ماکروها تغییر نکرده‌اند تا رفتار جستجو و سازگاری فایل‌ها محفوظ بماند. عرض کنترل برای متن فارسی تنظیم شده است تا برچسب زیر دستگیره نرود.

زیرعنوان‌های خواسته‌شده از کارت‌ها حذف شده‌اند: «عملیات داده»، «دسترسی سریع» بالای بازکردن مستقیم بخش، «پایش سیستم»، `Add Record`، `Search Engine`، `Remove & Undo`، `Tools & Automation`، `Activity`، `System` و «بخش ها». عنوان مستقل «دسترسی سریع» در خود منو حفظ شده است؛ درخواست حذف به زیرعنوان کارت داشبورد مربوط بود.

پاراگراف توضیح نمایش بلوک‌های Match از فرم جستجو حذف شده است. این حذف توضیح، مجوزها را تغییر نمی‌دهد: ویرایش مستقیم همچنان فقط برای سطح ۱ و ۲ مجاز است.

نام‌ها، داده‌های Excel، حساب‌ها، رمزها، مجوزها و مسیر مستقل شعبه/خودپرداز تغییری نکرده‌اند. توضیح فرم استانی نیز با رفتار فعلی هماهنگ شده است: انتخاب شعبه/خودپرداز، نه کپی پیش‌فرض داده‌های ردیف قبلی.
