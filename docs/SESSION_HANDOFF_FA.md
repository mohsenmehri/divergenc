## ۴. مرحلهٔ ۳ — آزمایشگاه EVE-NG (کارِ جاری)

- **دانلود**: از eve-ng.net → بخش Freemium نسخهٔ **7.2.0-18** → «EVE-NG PRO installation Full ISO» (همان ISO رایگان؛ سقف ۷ نود) — ~۱۰ گیگ. SHA256 مورد انتظار: `47add8c261dfb5c3d53a01fb185fcd692f1132c66b79d267fe6d7f8452b52502`. نسخهٔ Community 6.2 قدیمی/EOL است — نه.
- **Nested VT**: `systeminfo` ویندوز «A hypervisor has been detected» نشان داد → لایهٔ Hyper-V/VBS فعال است و VMware نمی‌تواند VT-x مجازی بدهد → **تصمیم: نودهای IOL** (پروسه‌اند، KVM نمی‌خواهند). vIOS/QEMU فقط با خاموش‌کردنِ آن لایه در ویندوزِ خانگی (اختیاری).
- **تنظیمات VM پیشنهادی**: Custom، Linux/Ubuntu 64-bit، ۲×۲ هسته، **۶ گیگ رم**، دیسک ۸۰ گیگ Thin، کارت ۱ = **VMnet1**، کارت ۲ = NAT (راحتیِ نصب).
- **شبکهٔ هدف**: EVE با IP ثابت مثلاً `192.168.97.130`؛ سوئیچِ IOL با SVI مثلاً `192.168.97.140`؛ رمزِ تجهیزِ آزمایشی **مستقل** (نه رمزهای سازمان)؛ SSH فعال؛ تأیید اثرانگشت کلید از کنسولِ تجهیز؛ **هرگز StrictHostKeyChecking=no**.
- **کارهای باقی‌ماندهٔ همین مرحله** (راهنمای کامل: `docs/EVE_NG_LAB_FA.md`؛ گام‌های A تا I): ✅ ۱) ISO تهیه و تأیید شد (۲۰۲۶/۱۰/۲۰ — `eve-pro-prod-bm-7.2.0-18-full.iso`، هش مطابق) ۲) VM را بساز و نصب کن (IP ثابت `192.168.97.130`) ۳) نود IOL سوئیچ (`192.168.97.140`) + IP + SSH ۴) تأیید کلید میزبان از کنسول + ثبت در `~/FAM-Linux-Lab/data/equipment_known_hosts` ۵) ثبتِ تجهیز در FAM ۶) اولین «بررسی تجهیزات» فقط‌خواندنی از داخل برنامه.

- **پس از آن** (نقشه): مرحلهٔ ۶ مهاجرت آزمایشی PostgreSQL → ۷ تست عملیات روی تجهیز آزمایشی (حساسِ 2960 فقط سخت‌افزار واقعی) → ۸ لایسنس/بسته‌بندی تجاری → ۹ پایلوت.

## ۵. قواعدِ الزامی (constraintهای ایستاده — هرگز نقض نشوند)

1. **هیچ استقرارِ عملیاتی (production) انجام نمی‌شود**؛ تست فقط در آزمایشگاه مجاز/فیزیکیِ مجاز.
2. **دیتابیس هرگز Reset/پاک نمی‌شود**؛ مهاجرت PostgreSQL فقط با انتقالِ تست‌شده و بکاپ.
3. **هیچ متنِ طولانی/هِرِداک در ترمینال VM/SSH پیست نشود** — فایل‌ها همیشه: دانلود از GitHub (`curl.exe --ssl-no-revoke` روی ویندوز) + `scp`. دستورها کوتاه و تک‌تک.
4. **رمزِ تجهیزات فقط در RAM** — هرگز در argv/URL/دیتابیس/لاگ/کانفیگ/فایل ماندگار؛ ASKPASS بدون‌رمز؛ پاک‌سازی گذرا.
5. **کلید میزبان SSH سخت‌گیرانه**؛ بدون `StrictHostKeyChecking=no`؛ بدون هکِ `_preferred_ciphers`؛ فقط استثنای محدودِ `aes128-cbc` (بدون wildcard ضعیفِ دیگر).
6. **بدون** enable / فرمان آزاد / write memory / copy running-config؛ تنها CLI خام مجاز: `show interfaces description` (محدود و مهارشده).
7. `interface range` دقیق: `FastEthernet0/6 , FastEthernet0/10` — هرگز بازهٔ اشتباه.
8. انتخابِ گروهی بدون سقف؛ **اجرا فقط ۱–۵ سوئیچ در هر نوبت**؛ روتر هرگز در عملیاتِ سوئیچ؛ بدون SSH/API به روتر در آن عملیات.
9. IP هر پورت مستقل حفظ می‌شود؛ حذفِ MAC قدیمی فقط با مجوزِ صریح؛ مسیرِ خالیِ err-disabled مشخص؛ بازگشتِ IPSG بعد از عملیاتِ موقت.
10. **پذیرشِ حساسِ 2960 (IPSG/DAI/Port-Security/errdisable) فقط روی سخت‌افزارِ واقعیِ مجاز** — نه سوئیچ مجازی، نه محیط عملیاتی.
11. تصاویرِ IOS سیسکو: **دستیار تولید/توزیع نمی‌کند**؛ از منابعِ مجازِ کاربر (CML/شرکت).
12. مجوزهای کاربر و محدوده‌های پنج‌گانهٔ تجهیزات حفظ می‌شوند؛ نشستِ رمزِ تجهیزات RAM-only تا خروجِ کامل.
13. بدون رمز/کلید/دیتابیس/لاگ/venv در ZIPها، اسکرین‌شات‌ها و اسناد؛ رمزهای واقعی هرگز در مخزن نیاید.
14. هرگز ریشهٔ مخزن یا `.git` حذف/تغییرنام نشود؛ کار فقط روی شاخهٔ همان سیشن.

## ۶. درس‌های عملی (تله‌ها — دوباره تکرار نشوند)

- **پیستِ لینک از گفت‌وگو** ممکن است آدرس را به `[url](url)` تبدیل کند و دستور بی‌صدا خراب شود — از کد‌بلاک استفاده کن؛ به کاربر بگو آدرس را چشمی چک کند.
- **اسکریپت PowerShell فارسی بدون BOM خراب می‌شود**: Windows PowerShell 5.1 فایل `.ps1` بدون BOM را ANSI می‌خواند و متن UTF-8 به‌هم‌ریخته parse را می‌شکند (`Unexpected token`). اسکریپت‌های ویندوزی را ASCII/انگلیسی می‌نویسیم (درس ۲۰۲۶/۱۰/۲۰ — verify_eve_iso.ps1).
- **ویندوز در ترمینال اوبونتو و برعکس**: با `cd` ساده یا پرامپت (`PS C:\...` در برابر `mohsen@fam-lab:~$`) جهت را مشخص کن؛ با مهربانی راهنمایی کن.
- **`curl.exe` در ویندوز بدون `--ssl-no-revoke`** ممکن است خطای 0x80092012 بدهد.
- **تغییر nginx.conf/compose نیاز به `docker compose up -d --force-recreate` دارد**؛ `restart` برای bind-mount کافی نیست.
- **مجوز پوشه‌ها**: `chmod -R a+rX` وقتی کارگر nginx نمی‌تواند فایلی را بخواند (خطای 404 با فایل موجود).
- **محیطِ sandbox ممکن است checkout را به نقطهٔ شروع شاخه بازگرداند** — اگر فایل‌ها ناقص بود: `git fetch origin arena/29133196-divergenc && git reset --hard FETCH_HEAD` و ادامه بده؛ **بعد از هر مرحله push کن**.
- ساختِ بسته‌ها: تغییر در `server/` یا `src/` → `build_shared.py` → `package_custom_access_updates.py` (و `--server-only` برای آینهٔ ریشه) → `package_linux_lab.py` → هر دو `verify_*` → تست‌ها.
