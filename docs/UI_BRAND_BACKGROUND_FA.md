# یکپارچه‌سازی لوگو و پس‌زمینهٔ فام

در LOCAL و SERVER:

- صفحهٔ ورود، همان لوگوی اصلی داخل منوی داشبورد را نمایش می‌دهد؛ تصویر بازطراحی یا دوباره رنگ‌آمیزی نشده است.
- زیر لوگو، عبارت دقیق «تجارت الکترونیک و فناوری اطلاعات ملل (فام)» قرار دارد.
- در صفحهٔ انتخاب پایگاه داده / مدیریت تجهیزات، نوشتهٔ انگلیسی بالای عنوان با همین لوگو و نام فارسی جایگزین شده است.
- در ورود اولیهٔ SERVER/IIS نیز لوگوی یکسان وجود دارد؛ بدون فایل تصویر جانبی یا درخواست اینترنت. محدودیت اجرای script/style صفحهٔ ورود مرکزی حفظ شده است.
- پس‌زمینهٔ تختِ مخصوص تجهیزات و قاعدهٔ مخفی‌کردن fx-stage حذف شده‌اند. تجهیزات اکنون از پس‌زمینه و افکت‌های مشترک داشبورد استفاده می‌کند؛ کنترل‌های زمینهٔ قبلی حفظ شده‌اند.
- تم اصلی تیره پیش‌فرض مانده، انتخاب تم ذخیره‌شدهٔ کاربر حفظ می‌شود و در تم روشن، افکت‌های تیره همچنان طبق سیاست مشترک مخفی‌اند. تنظیمات reduced-motion تغییر نکرده‌اند.
- صفحهٔ انتخاب دو فضای کاری پس از ورود برقرار است؛ جابه‌جایی بخش خروج از حساب نیست. موجودی، دسته‌بندی‌ها، مجوزها، رمزها و کلیدهای storage reset نشده‌اند.

## اجرای LOCAL

`FAM-Custom-Access-LOCAL-Patch.zip` جدید را در پوشهٔ جدید استخراج کنید و `FAM.html` یا `START-FAM.cmd` را باز کنید. قبل از جایگزینی نسخهٔ کاری، بکاپ مستقل بگیرید؛ اطلاعات مرورگر را پاک نکنید. لوگو داخل HTML تعبیه شده است.

## نصب SERVER

از پچ SERVER کامل جدید استفاده کنید، نه کپی‌کردن HTML به پوشهٔ عمومی IIS. راهنمای نصب و بازگشت در `SERVER_REVIEW_FIX_PATCH_FA.md` و `README_FA.txt` داخل بسته است. این نوبت، قابلیت فقط‌خواندنی تشخیص کلاینت نیز به SERVER اضافه شده؛ راهنمای مستقل `CLIENT_MOVE_DIAGNOSIS_FA.md` را بخوانید. LOCAL هنوز SSH یا تشخیص واقعی سوئیچ ندارد.

## بررسی نسخه

در صفحهٔ برنامه، meta با نام `fam-brand-release` مقدار `FAM-BRAND-BACKGROUND-20261018` دارد. بررسی hash ZIP نیز لازم است. روی مرورگر واقعی، تطابق تصویر با لوگوی منو، ترتیب لوگو/نام، بازشدن خودکار انتخاب بخش، عرض‌های ۳۲۰/۳۹۰/۷۶۸/۱۴۴۰ و یکسان‌بودن background/FX داشبورد و تجهیزات در هر دو تم آزمایش شده‌اند؛ درخواست اینترنتی برای لوگو وجود ندارد.
