# FAM UI-05 — عنوان سازمان و نام کاربر

## ظاهر

- نام فارسی سازمان در عنوان صفحه و منو: «تجارت الکترونیک و فناوری اطلاعات ملل (فام)»؛ زیرعنوان انگلیسی نیز هماهنگ شده است.
- متن معرفی: «سامانه مدیریت اطلاعات شبکه‌ی LAN, WAN، سراسری شعب و خودپردازها، مراکز داده و ...».
- برچسب معرفی: «اداره‌ی ارتباطات و شبکه» بدون پیشوند NOC.
- شمارندهٔ «بخش • رکورد ایندکس • Web User» از سربرگ حذف شده است. در همان محل فقط نام نمایشی و علامت ویرایش دیده می‌شود؛ آمار دیگر بخش‌های داشبورد حفظ شده‌اند.

## تغییر نام کاربر

روی WEB USER در بالای صفحه کلیک کنید، رمز مدیر را تأیید کنید و سپس نام جدید را وارد کنید. نام خالی پذیرفته نمی‌شود و حداکثر طول ۶۰ نویسه است. انصراف، بستن پنجره یا Escape تغییری ایجاد نمی‌کند. برای هر ویرایش، تأیید مجدد لازم است.

نام در ذخیره‌سازی محلی و IndexedDB حفظ می‌شود؛ نام جدید در ثبت‌های بعدی تاریخچه نیز استفاده می‌شود. نام از پشتیبان دادهٔ واردشده جایگزین نمی‌شود تا ورود JSON مسیر دیگری برای تغییر نام نباشد. نام قدیمی پیش‌فرض به WEB USER یکدست می‌شود.

## تأیید رمز و حدود امنیت

- همه مسیرهای باز کردن قفل در **نسخهٔ وب** از رمز یکسان درخواست‌شده استفاده می‌کنند: پنل کنترل، ابزار UnprotectCP، همه بخش‌ها و قفل یک بخش. رمزهای قبلی پذیرفته نمی‌شوند.
- ورودی‌ها از نوع password هستند؛ ارقام فارسی و عربی هم پذیرفته می‌شوند. پس از بستن پنجره، مقدار ورودی و حافظهٔ موقت فرم پاک می‌شود. رمز در راهنما، پیام، تاریخچه یا دادهٔ پشتیبان ثبت نمی‌شود.
- در کد اجرایی فقط چکیدهٔ رمز برای مقایسه نگه داشته می‌شود، نه متن خام آن. این کار **امنیت سمت سرور یا مقاومت رمز کوتاه در برابر حدس را فراهم نمی‌کند**.
- مقادیر رمز تاریخی در بستهٔ مرجع VBA تعبیه‌شده با `[REDACTED]` جایگزین شده‌اند؛ این پوشاندن هم در نمایش و هم در دانلود تکی/کلی اعمال می‌شود. خروجی VBA مرجع است و با این ثابت‌های پوشانده‌شده نباید برای اجرای مستقیم ماکرو استفاده شود.
- **فایل اصلی XLSM و ماکروهای داخل آن تغییر نکرده‌اند.** این نسخه رمز فایل اکسل، پروژهٔ VBA یا هر سامانهٔ خارجی را عوض نمی‌کند.
- این برنامه یک HTML مستقل است؛ تأیید مدیر فقط یک کنترل محلی رابط است، نه حساب مدیر یا مجوز قابل اتکای امنیتی. دارندهٔ فایل می‌تواند کد و حافظهٔ مرورگر را تغییر دهد. احراز هویت واقعی به سرور و کنترل مجوز در سمت سرور نیاز دارد.
- مقایسهٔ چکیده از Web Crypto استفاده می‌کند؛ برنامه را مستقیماً به‌صورت فایل یا از HTTPS باز کنید. در محیط فاقد این قابلیت، تأیید رمز رد می‌شود.

## آزمون‌ها

`npm test`: **۱۸ تست موفق**. چهار آزمون جدید متن‌های دقیق، نمایش نام در موبایل/دسکتاپ، تأیید مدیر، رد رمز قبلی، انصراف، نام خالی، جلوگیری از تفسیر HTML در نام، ماندگاری پس از reload، حفظ نام هنگام ورود JSON، تمام مسیرهای بازکردن قفل و عدم نمایش رمز در توضیحات/سورس/خروجی مرجع را پوشش می‌دهند. آزمون‌های قبلی منو، دسته‌بندی، فرم‌های سریع و اندازه‌های ۳۲۰ تا ۱۹۲۰ نیز موفق‌اند.
