# پیش‌نمایش LOCAL فرم تعویض MAC

فایل: `releases/FAM-Client-MAC-LOCAL-Preview.zip`، شامل HTML مستقل و `README_FA.txt`.

- ZIP را استخراج و HTML را با Chrome/Edge باز کنید. برای حساب تازهٔ محلی: `admin` / `1109`؛ حساب برنامه است، نه رمز تجهیز. حساب‌ها/اطلاعات موجود ریست نمی‌شوند.
- مسیر: ورود ← تجهیزات ← بررسی پورت‌ها.
- سوئیچ‌های مجازِ ثبت‌شده در موجودی محلی نمایش داده می‌شوند. در موجودی خالی، کادر IP «فقط برای پیش‌نمایش فرم» یک هدف موقت اضافه می‌کند؛ در موجودی ذخیره نمی‌شود و اتصال ندارد.
- سوئیچ را انتخاب کنید؛ پورت را خالی بگذارید یا مثلاً `7` وارد کنید؛ تیک IP دستی را امتحان کنید و «نمایش مسیر انتخاب‌شده — بدون اجرا» را بزنید.
- پورت خالی شرح مسیر قبلی Err-disabled است. پورت پر شرح مسیر تعویض MAC همان پورت است. با تیک دستی IP قبلی بدون تغییر و MAC جدید در binding و Inspection قرار خواهند گرفت؛ LOCAL هیچ IP واقعی از سوئیچ نمی‌خواند و IP را حدس نمی‌زند.
- این نسخه صرفاً مرور ظاهر/مسیر است: **SSH، گرفتن MAC، نتیجهٔ ساختگی سالم/موفق، تغییر سوئیچ یا دریافت رمز تجهیز ندارد.** عملیات واقعی فقط SERVER با پیش‌بررسی و تأیید جداگانه انجام می‌شود. Sticky قدیمی خودکار حذف نمی‌شود.
- انتخاب‌ها/IPهای موقت فقط در RAM هستند؛ refresh پاکشان می‌کند. موجودی/حساب‌ها مانند LOCAL اصلی باقی می‌مانند؛ پیش از استفادهٔ کاری بکاپ مستقل بگیرید.

ساخت بازتولیدپذیر: `python scripts/build_mac_local_preview.py`. این builder فقط variant جدید می‌سازد؛ `FAM.html` اصلی و SERVER/payload/ZIP قبلی تغییر نمی‌کنند. marker برابر `FAM-LOCAL-MAC-PREVIEW-20261018` است.

پذیرش اجراشده: `node --test tests/equipment-mac-local-preview.test.cjs`، چهار تست مرورگر file:// پاس؛ بدون درخواست HTTP(S) و بدون خطای JavaScript. موارد: ورود و ناوبری اصلی، پورت خالی، Fa0/7 با/بدون تیک، نبود حدس/خواندن IP، اعتبارسنجی ۱ تا ۲۴، invalidation، عدم ثبت هدف موقت، refresh و عرض‌های ۳۹۰/۷۶۸/۱۴۴۰. تجهیزات واقعی و Windows/IIS در این بررسی دخیل نیستند.
