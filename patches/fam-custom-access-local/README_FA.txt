FAM — نسخهٔ محلی / آفلاین برای بررسی UI تجهیزات

روش ورود
1) همهٔ فایل‌های ZIP را در یک پوشهٔ جدید Extract کنید.
2) FAM.html را با Microsoft Edge یا Google Chrome باز کنید؛ یا START-FAM.cmd را اجرا کنید.
3) در اولین اجرا (پروفایل مرورگر بدون حساب قبلی):
   نام کاربری: admin
   رمز پیش‌فرض آزمایشی نسخهٔ محلی: 1109
4) پس از ورود، دکمهٔ سه‌خط بالای صفحه را بزنید و از منوی سمت راست تب «تجهیزات» را باز کنید.

این حساب صرفاً حساب پیش‌فرض نسخهٔ محلی است؛ رمز سرور یا تجهیز نیست. اگر قبلاً در همان مرورگر رمز حساب محلی خود را تغییر داده‌اید، با همان رمز قبلی وارد شوید. این بسته حساب‌های قبلی را reset نمی‌کند. برای آزمایش تمیز بدون پاک‌کردن اطلاعات قبلی، از یک پروفایل جدید مرورگر استفاده کنید.

این همان صفحهٔ کامل FAM محلی با مدیریت کاربران و دسترسی‌های سفارشی است، نه یک صفحهٔ تجهیزات جداگانه. واردکردن Excel برای مشاهدهٔ تب تجهیزات لازم نیست. داده‌ها و حساب‌های محلی قبلی را پاک نکنید؛ برای نصب کنار نسخهٔ قبلی، فایل را در پوشهٔ جدید باز کنید.

تجهیزات — فقط پیش‌نمایش نمایشی
- بدون سرور، IIS، Python، Connector، Worker، Token یا نصب برنامه.
- هیچ اتصال SSH یا API به سرور FAM/تجهیز انجام نمی‌شود.
- همهٔ وضعیت‌ها ساختگی‌اند و برچسب «نمایشی» دارند؛ برای بررسی ظاهر و جریان کار در خانه هستند.
- رمز واقعی تجهیز را وارد نکنید؛ در فرم تجهیزات فقط اطلاعات ساختگی وارد کنید.
- پس از بررسی یا تأیید بازیابی، فیلد رمز تجهیزات پاک می‌شود. اطلاعات ورود تجهیز در storage، فایل یا شبکه نوشته نمی‌شود. حساب ورود خود FAM طبق رفتار نسخهٔ محلی در مرورگر نگه‌داری می‌شود.

سناریوهای قابل آزمایش
- وضعیت پاک: هیچ پورت Err-disabled وجود ندارد.
- یک پورت نمونه Gi0/1 با Description و بازیابی موفق پس از تأیید همان پورت.
- باقی‌ماندن Err-disabled پس از بازیابی.
- نبودن خطا در بررسی پیش از بازیابی (بدون اعمال تغییر).
- خطای احراز هویت، timeout و خطای اتصال.

برای آزمایش بازیابی، پس از بررسی یک رمز ساختگی دوباره وارد کنید و «تأیید رفع خطا» را بزنید. هیچ دستور واقعی اجرا یا تنظیمی ذخیره نمی‌شود. فردا آزمایش اتصال واقعی باید با نسخهٔ SERVER روی سرور محل کار انجام شود؛ این فایل جایگزین نسخهٔ SERVER نیست.

ایمنی و صحت
- قبل از جایگزینی هر فایل قبلی، یک کپی پشتیبان بگیرید؛ ترجیحاً نسخهٔ جدید را کنار نسخهٔ قبلی باز کنید.
- ZIP هیچ دادهٔ Excel، دیتابیس سرور، رمز واقعی، Token، private key، log یا venv ندارد.
- SHA256SUMS.txt صحت FAM.html را ثبت می‌کند.
