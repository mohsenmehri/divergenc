نسخهٔ محلی / آفلاین — مرجع مدیریت دسترسی سفارشی

این بسته FAM.html فعلیِ آفلاین را شامل می‌شود. این نسخه از قبل دارای مدیریت کاربران بدون «سطح‌بندی» نمایشی است: دسته‌های داده، مناطق استانی و مجوزهای ریزعملیاتی. هیچ تغییر تازه‌ای به منطق نسخهٔ محلی اعمال نشده است؛ این فایل برای هم‌نسخه‌سازی یا بازگردانی نسخهٔ محلی مرجع ارائه می‌شود.

روش استفاده: از FAM.html فعلی یک کپی پشتیبان بگیرید، سپس FAM.html این بسته را جایگزین کنید. داده‌های Excel/JSON و worksheetها داخل این ZIP نیستند و تغییری نمی‌کنند.

فایل SHA256SUMS.txt، hash فایل FAM.html داخل همین بسته را ثبت می‌کند. این بسته backend یا web.config سرور مرکزی نیست؛ hardening سرور فقط در بستهٔ SERVER و FAM-Central-IIS اعمال می‌شود.
