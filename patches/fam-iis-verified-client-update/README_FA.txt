به‌روزرسانی تأییدشدهٔ رابط FAM برای IIS — FAM UI-17.1
تاریخ: ۲۰۲۶-۱۰-۱۳

این بسته برای رفع حالت «فایل در مسیر اشتباه کپی شده» ساخته شده است. اسکریپت به‌جای حدس‌زدن C:\FAM، سایت IIS دارای binding HTTPS با نام communication-02.toosbank.corp را پیدا می‌کند، Physical Path واقعی همان سایت را می‌خواند، سپس فقط FAM.html و web.config همان مسیر را به‌روزرسانی می‌کند.

روش اجرا:
۱. ZIP را کامل Extract کنید؛ ساختار پوشهٔ payload را تغییر ندهید.
۲. روی خود سرور، روی APPLY-FAM-IIS-CLIENT-UPDATE.cmd راست‌کلیک و Run as administrator را انتخاب کنید.
۳. تا نمایش FAM IIS CLIENT UPDATE: SUCCESS صبر کنید.
۴. در خروجی، Actual IIS physical path و مسیر Backup ثبت می‌شود. این دو را نگه دارید.

اسکریپت قبل از نصب SHA-256 هر دو payload را کنترل می‌کند، از FAM.html و web.config قبلی در C:\ProgramData\FAM\client-update-backups نسخهٔ پشتیبان می‌گیرد، مسیر Physical Path واقعی IIS را تشخیص می‌دهد، سایت هدف را بازراه‌اندازی می‌کند و پس از آن وجود ویژگی‌های نسخهٔ جدید را کنترل می‌کند. اگر هر کنترل ناموفق باشد، دو فایل قبلی به‌صورت خودکار برگردانده می‌شوند.

این بسته فقط FAM.html و web.config را تغییر می‌دهد. به دیتابیس، app.py، حساب‌ها، داده‌های Excel، binding، DNS، گواهی و تنظیمات IIS دیگر دست نمی‌زند.

web.config جدید برای هر درخواست FAM.html هدرهای no-store/no-cache را می‌فرستد. بنابراین کاربران پس از باز کردن مجدد سایت یا یک F5 عادی نسخهٔ تازه را می‌گیرند و نیازی به پاک‌کردن Cache یا Ctrl+F5 ندارند. صفحه‌ای که از قبل باز مانده، باید یک‌بار Reload شود.

نشانهٔ موفقیت در رابط: در پایین نوار کناری «FAM UI-17 · 2026-10-13» دیده می‌شود و مدیرهای سطح ۱ و ۲ در دسته‌های غیر استانی گزینهٔ «مدیریت بخش‌ها» را می‌بینند.
