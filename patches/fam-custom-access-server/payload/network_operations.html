Inventory آزمایشگاهی

آدرس مدیریت، نام کاربری، رمز، Enable، RADIUS و SNMP در Inventory FAM ثبت نمی‌شوند.

Worker داخلی خودکار

Worker فقط روی همین سرور FAM و زیر هویت غیرتعاملی Local Service اجرا می‌شود. Pairing دستی، Token مرورگر و حساب نام‌دار وجود ندارد.

بررسی مستقیم Err-disabled

کاربر IP، نام کاربری و رمز SSH را خودش وارد می‌کند: برای Router از RADIUS خودش و برای Switch از حساب Local همان تجهیز. پیش از ارسال، مرورگر این مقادیر را با کلید عمومی Worker رمز می‌کند. FAM/IIS فقط متن رمزگذاری‌شدهٔ موقت را تا پایان همان Job حمل می‌کند و نمی‌تواند IP یا رمز را بخواند؛ پس از ثبت نتیجه نیز پاک می‌شود. SSH فقط از خود سرور FAM انجام می‌شود.

برای استفاده، Worker باید یک‌بار اجرا شده و کلید رمزنگاری خود را ثبت کرده باشد.

رفع کنترل‌شدهٔ Err-disabled

این فرم فقط پس از انتخاب یک پورت گزارش‌شده از نتیجهٔ بررسی فعال می‌شود. Worker ابتدا همان پورت را دوباره بررسی می‌کند؛ فقط اگر هنوز Err-disabled باشد، تنها روی همان Interface توالی محدود recovery را اجرا و سپس وضعیت را دوباره کنترل می‌کند. هیچ دستور آزاد، Enable / Enable Secret یا ذخیرهٔ تنظیمات وجود ندارد.

ابتدا از نتیجهٔ یک بررسی موفق، پورت Err-disabled را انتخاب کنید.
