نصب روی محیط تست
این پچ برای نصب موجود FAM در C:\FAM و C:\FAMData است، نه نصب مستقل.
۱) پیش از تغییر، از SQLite زنده با روش backup تأییدشدهٔ FAM نسخهٔ مستقل بگیرید و نگه دارید. بکاپ کد جایگزین بکاپ دیتابیس نیست.
۲) ZIP را روی خود سرور Extract کنید و APPLY-CUSTOM-ACCESS-UPDATE.cmd را با Run as administrator اجرا کنید.
۳) فقط پیام CUSTOM ACCESS + PRIVATE FAM UI UPDATE APPLIED. به معنی پایان موفق است؛ سپس FAM را refresh کنید.
ابتدا روی کپی محیط تست نصب کنید. نصب Windows/IIS و ارتباط با سوئیچ واقعی اینجا آزمایش نشده‌اند.

پیش‌نیاز اتصال
OpenSSH Client ویندوز (C:\Windows\System32\OpenSSH\ssh.exe) و پشتیبانی aes128-cbc لازم است؛ نصاب پیش از تغییر آن را بررسی می‌کند.
.NET Framework 4.x و compiler داخلی csc.exe برای ASKPASS موقت لازم است؛ wheel یا وابستگی جدید نصب نمی‌شود.
اتصال فقط سرور FAM ← تجهیز است؛ Connector، Worker، Token، Pairing یا سرویس جدیدی وجود ندارد.
Host key با C:\FAMData\equipment\known_hosts و accept-new بررسی می‌شود؛ تغییر کلید رد می‌شود. FAM_EQUIPMENT_HOST_KEY_POLICY=strict فقط کلید از قبل مورد اعتماد را می‌پذیرد. StrictHostKeyChecking=no استفاده نمی‌شود.
فقط استثنای محدود aes128-cbc فعال است؛ 3des-cbc / aes192-cbc / aes256-cbc مجاز نیستند.

بازطراحی از نو، نه پوسته روی رابط قبلی
رابط درخت/کارت/زیرگروه و تب‌های تو‌در‌توی قدیمی حذف شده است. واژهٔ رابط «تجهیز» است.
مقصدهای مستقیم: فهرست تجهیزات، بررسی پورت‌ها، استانداردها، پیکربندی آفلاین، ورود و خروج اکسل، دسته‌بندی‌ها.
فهرست جست‌وجوی نام/IP/مدل/محل، فیلتر پنج‌گانه، مرتب‌سازی و صفحه‌بندی ۲۵تایی دارد. فهرست انتخاب SSH حداکثر ۵۰ نتیجهٔ جست‌وجو را رندر می‌کند.
جزئیات هر تجهیز در همان صفحه باز می‌شود؛ باز کردن آن هیچ SSH یا فرمانی اجرا نمی‌کند. «کامل» فقط کامل‌بودن مشخصات است؛ وضعیت آنلاین/سلامت جمع‌آوری نشده است.
افزودن، ویرایش، حذف با تأیید، خروج از دسته، مدیریت دسته‌ها و میان‌برهای قبلی حفظ شده‌اند؛ حذف میان‌بر اطلاعات را حذف نمی‌کند.
فرم RADIUS جلوی ورود به فهرست یا ابزار آفلاین نیست. حساب SSH / RADIUS را فقط در «بررسی پورت‌ها» وارد کنید.
پیکربندی و تطبیق استانداردها آفلاین‌اند؛ اجرای گروهی کانفیگ، Enable یا ترمینال آزاد اضافه نشده است.

اطلاعات و دسترسی‌ها
موجودی، میان‌برها و استانداردهای بدون رمز در equipment_state همان SQLite نگهداری می‌شوند؛ در browser storage تجهیزات مرکزی ذخیره نمی‌شوند.
نام کلیدها/شناسه‌ها و ساختار داده تغییر نکرده است. بازطراحی اطلاعات، حساب، worksheet یا تنظیمات دسترسی را پاک یا از نو مقداردهی نمی‌کند. دادهٔ LOCAL خودکار به سرور منتقل نمی‌شود.
مجوزهای مستقل و پنج محدودهٔ نوع/مدل/منطقه/نوع محل/محل، با «و» اعمال می‌شوند. * یعنی همهٔ فعلی/آینده، انتخاب خالی یعنی هیچ. سرور مستقل از ظاهر، نشست، Origin، CSRF، عملیات و محدوده را اعتبارسنجی می‌کند.
ثبت تا تأیید سرور مسدود است. قطع ارتباط/تعارض به معنی موفقیت نیست و درخواست خودکار تکرار یا بازنویسی نمی‌شود؛ وضعیت قطعی را دریافت و تغییر را بازبینی کنید.
Excel از دسته‌های جاری و فهرست‌های Stop وابسته ساخته می‌شود؛ بعد از تغییر دسته‌ها فرم تازه بگیرید. importer و سرور مستقل داده و مجوزها را بررسی می‌کنند.
پاک‌سازی تاریخچه با مجوز و تأیید جدا انجام می‌شود؛ داده‌ها/حساب‌ها و نسخه‌های داخلی لازم برای بازگشت را حذف نمی‌کند.

بررسی پورت‌ها و رفع
۱) یک تا پنج سوئیچ مجاز را انتخاب و حساب مشترک SSH / RADIUS آن‌ها را وارد کنید؛ برای حساب متفاوت نوبت جدا اجرا کنید.
۲) «بررسی پورت‌ها» را بزنید. دو فرمان ثابت show interfaces status و show interfaces description در یک نشست/احراز هویت خوانده می‌شوند؛ اتصال دوم خودکار حذف شده است.
۳) نام/IP سوئیچ و پورت کنار هم نمایش داده می‌شوند؛ پورت‌های خطادار را انتخاب، نام/IP/پورت دقیق را در پنجرهٔ تأیید بازبینی و سپس رفع را تأیید کنید.
رفع فقط pre-check، shutdown / no shutdown روی همان Interface و post-check است؛ حداکثر پنج پورت، یکی‌یکی. انصراف هیچ درخواست رفعی نمی‌فرستد. Enable، command آزاد، write memory و copy running-config ممنوع‌اند.
پورت باید در بررسی قبل و بعد وجود داشته باشد؛ ناپدیدشدن پورت موفقیت نیست. err-disabled / errdisable / errdisabled خطاست؛ disabled / notconnect / connected خطا محسوب نمی‌شود.
احراز هویت ناموفق، timeout، جدول ناقص یا پاسخ نامعتبر همیشه نامشخص/ناموفق‌اند، نه «سالم». وضعیت آنلاین، CPU یا مقادیر ساختگی ارائه نمی‌شود.
IP دستیِ خارج از موجودی فقط با * در هر پنج محدوده مجاز است؛ کاربر محدود فقط IP موجود در موجودی مجاز را بررسی می‌کند. IP دستی ذخیره نمی‌شود.
خروجی show int des در بخش بازشدنی کنار نام/IP هر سوئیچ، با همان فاصله و سطرها نمایش داده می‌شود؛ دکمهٔ خواندن مستقل نیز وجود دارد. این فقط جدول مجاز است، نه ترمینال؛ بنر/prompt/خطای داخلی و متن حساس حذف یا REDACTED می‌شوند. خروجی با textContent است، نه HTML.
زمان آماده‌سازی و مجموع SSH + احراز هویت + اجرای دستورها نمایش داده می‌شود؛ زمان تفکیکی RADIUS نیست و درصد افزایش سرعت واقعی ادعا نمی‌شود.
بودجه‌ها: نشست بررسی ترکیبی ۵۰، helper برابر ۵۵، والد ۶۵ و مرورگر ۱۱۰ ثانیه؛ سقف‌اند نه تأخیر عمدی. عملیات قدیمی و رفع محدودیت‌های قبلی خود را دارند.
در رفع، سه نشست ایمنی حفظ شده ولی ASKPASS بدون رمز فقط یک‌بار در همان درخواست ساخته و در finally حذف می‌شود؛ نه cache مشترک و نه credential ذخیره‌شده.

رمز و نتایج
حساب سوئیچ فقط در RAM همان صفحه تا خروج FAM باقی است؛ تغییر بخش آن را پاک نمی‌کند، refresh/خروج/انقضای نشست پاک می‌کند.
سرور رمز را فقط برای درخواست جاری و environment فرزند SSH مصرف می‌کند؛ در argv، URL، فایل، config، DB یا log نوشته نمی‌شود. ASKPASS source/exe رمز ندارد و موقت است.
نتیجه، ticket رفع، IP دستی و متن کانفیگ در موجودی، workbook، history یا browser storage نوشته نمی‌شوند.
ترک بخش، فرمانی را که قبلاً به سرور فرستاده شده تضمیناً لغو نمی‌کند؛ پیش از اقدام مجدد وضعیت را بررسی کنید. درخواست خودکار تکرار نمی‌شود.

بسته و بازگشت
payload با SHA256SUMS.txt بررسی می‌شود؛ رمز، Token، SQLite، PFX، private key، known_hosts، log و venv داخل بسته نیست.
کد و UI فعلی در C:\FAMData\backups\custom-access-<date> پشتیبان‌گیری می‌شوند. سرویس شناخته‌شدهٔ FAM-Central کنترل‌شده متوقف و بعد از جایگزینی شنود داخلی 8765 بررسی می‌شود.
در شکست، فایل‌ها به حالت قبل برمی‌گردند؛ فایل تازه‌ای که قبلاً وجود نداشته حذف می‌شود. مهاجرت‌های افزایشی سازگاری اطلاعات قبلی را حفظ می‌کنند؛ DB و کاربران از نو ساخته نمی‌شوند.

اعتبارسنجی
۱۰۳ تست JavaScript شامل مرورگر/مدل/ساخت موفق؛ بک‌اند ۱۲۲ تست، ۱۲۱ موفق و ۱ مورد وابسته به محیط skip.
تست مرورگر دو نشست مرکزی و مسیر SSH/API با executor ساختگی، دسترسی، ثبت معلق/تعارض، IP دستی، مالکیت پورت، تأیید/انصراف، جدول امن و RAM-only موفق بوده‌اند.
این‌ها آزمایش Windows/IIS/RADIUS یا ارتباط با تجهیز واقعی نیستند؛ هیچ تجهیز واقعی در این محیط تماس گرفته نشده است.
